## Queued items don't escape death
- A queued job's items used to survive a death with the mind. Now a body's jobs that took items end when it dies, and the dust comes back. The main body's items drop with its inventory, unless `keepInventory` is on. A shell that dies while you're in it keeps them in its wreck. The owner's yes, from the old PC's review.
- From the old PC's review of this: moving items between a player file and a chunk can lose them in a crash, because the two save apart. So they go in the shell's snapshot before the job ends, and the outbox holds them. A shell scrapped or killed by a command leaves the job alone, and any body can cancel it. `onDrops` runs last, so a mod that cancels the drops leaves the job alone.
- Tests: `aDyingBodyDropsWhatItsJobsTook`, `aWreckKeepsWhatItsShellsJobsTook`, `aLostBodyTakesOnlyItsOwnJobsThatTookItems`, and the restart test `aShellsQueuedItemsOutliveACrash`, which CI runs.
