## A wreck drifts, and its marker stays
- A main body's wreck drifts in space at 0.3 blocks a second in a random direction, only while it is loaded, and stops against a block. The HUD marker follows it and stays until the wreck has been emptied, as the Danger page asked; a marker with no wreck still clears on arrival. Only the newest wreck has a marker: older ones wait for the Wreck Finder.
- Test: `aWreckDriftsAndItsMarkerStaysUntilItIsEmptied`.
