## The utility mount
- A new mount kind for always-on modules: `ModuleKind.UTILITY`, last in the list because the network sends a kind by its place. Nothing goes in it yet; the first modules come next.
- **Default chosen (safest, reversible):** the owner gave no number, so each body's core section offers 1 on the Drone and Mech, 2 on the Ship and Shuttle and 3 on the Titan. Core sections, because a body always has one. Saved bodies get the mounts with no migration: a section's stats are a default component in code, not in the save.
