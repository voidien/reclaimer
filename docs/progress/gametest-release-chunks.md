## GameTests let go of chunks between batches
- Every forced test area kept about 625 half-made chunks in memory for the whole run, and the remote control tests took a fresh world past 10 GB (66,000 chunks, about 17 million sections). `GameTestBatchChunkMixin` releases all forced chunks as each batch starts, when every test before it has finished. An earlier try made things worse because each unloading chunk was written and the data filled the heap. So no test run writes half-made chunks now (`GameTestChunkSaveMixin`): no test touches them and the generator makes them again the same way. Restart tests keep their chunks. `main`'s GameTests now get the 10 GB heap too (they were overriding it).
- It also ends forced chunks carrying over between local runs, an entry under "Ideas for the owner".
